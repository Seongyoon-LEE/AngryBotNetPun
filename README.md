# 🚀 3D 탑뷰 슈팅 액션 TPS: AngryBotNetPun

**멀티플레이 방을 생성해 플레이어끼리 실시간으로 대전하는 탑뷰 TPS 슈팅 게임입니다.**

<br>

🎥 **게임 영상**  
https://youtu.be/k672HtAcnNU

<br>

## ✨ 주요 기능

- **🌐 멀티플레이 지원**: Photon 2 Networking을 통한 실시간 멀티플레이 구현  
- **🎨 그래픽 효과**: Post Processing과 Universal RP를 활용해 높은 그래픽 품질 제공  
- **⚔️ 데스매치 모드**: 플레이어 사망 시 랜덤 리스폰으로 긴장감 넘치는 전투 진행  

<br>

## 🛠️ 개발 환경

- **Engine**: Unity  
- **Language**: C#
